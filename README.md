# ThumbX

A responsive YouTube thumbnail editor built with React + Vite.

## Run locally
1. Install Node.js (or use a browser-based development environment).
2. Run `npm install`
3. Run `npm run dev`
4. Open the local URL shown by Vite.

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import the repository.
3. Framework preset: **Vite**.
4. Build command: `npm run build`
5. Output directory: `dist`
6. Deploy.

## Included
- 1280×720 canvas preview
- Upload an image from your device
- Editable headline, subtitle, colors and font
- Starter templates
- PNG export
- Responsive layout and Free/Premium presentation

## Important
The Premium button is a visual/demo upgrade prompt. Real subscriptions, accounts,
cloud saving and payment processing require a backend and a payment provider.
Uploaded images are processed locally in the browser and are not uploaded to a server.
